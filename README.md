# WB Video Analyzer

Веб-интерфейс для анализа наличия товаров на видео с помощью технологии компьютерного зрения. Проект создан в стиле маркетплейса Wildberries для демонстрации поиска товаров на видео по их фото.

## 🌟 Особенности

- Загрузка и анализ видео на наличие выбранных товаров
- Визуализация результатов анализа в веб-интерфейсе
- Использование технологии самоконтролируемого обучения (SSL) для поиска объектов
- Современный интерфейс в стиле Wildberries с использованием React и TailwindCSS
- Детальные графики и статистика распознавания

## 🔧 Технические требования и установка

### Системные требования

- Python 3.8 или выше
- Node.js 16 или выше
- NVIDIA GPU с поддержкой CUDA (рекомендуется для быстрой работы)
- 12 GB RAM минимум (16 GB рекомендуется)

### Установка модели

Перед запуском приложения необходимо загрузить предобученную модель SSL:

1. Загрузите модель по ссылке: https://disk.yandex.ru/d/AQuNJMU5D-q9FQ (пароль: 1510)
2. Создайте директорию `models` в корне проекта
3. Поместите файл модели (`ssl_model_epoch_80.pth`) в директорию `models`

### Установка и запуск (Windows)

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Wijerty/wb-analyzer-ui.git
cd wb-analyzer-ui
```

2. Запустите скрипт установки зависимостей для Windows:
```bash
install_dependencies.bat
```

3. Запустите бэкенд (Flask):
```bash
cd wb-analyzer-ui
python server.py
```

4. В отдельном терминале запустите фронтенд (React):
```bash
cd wb-analyzer-ui
npm start
```

5. Откройте приложение в браузере по адресу: http://localhost:3000

### Установка и запуск (Linux/Mac)

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Wijerty/wb-analyzer-ui.git

2. Запустите скрипт установки зависимостей для Linux/Mac:

Также возможен запуск через Docker:

```

## 🧠 Принцип работы

1. Пользователь загружает фотографии товаров и видео для анализа через веб-интерфейс
2. Сервер обрабатывает видео кадр за кадром, используя модель SSL
3. Для каждого товара вычисляется показатель сходства с объектами на видео
4. Если показатель сходства превышает пороговое значение, товар считается найденным
5. Результаты анализа визуализируются в веб-интерфейсе

## 📝 Примечания

- Для анализа большого количества видео рекомендуется использовать GPU
- Качество распознавания зависит от качества загруженных фотографий товаров
- Для лучших результатов рекомендуется настраивать порог распознавания в зависимости от типа товаров
- Предобученная модель не входит в репозиторий из-за размера файла (около 94 МБ)
